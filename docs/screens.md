# 화면 설계서 (screens.md)

Streamlit 단일 앱. 로그인 후 role(USER/MANAGER/ADMIN)에 따라 메뉴가 분기된다.
관리자·매니저 화면은 `layout="wide"` PC 기준, 직원 화면은 모바일 폭(390px) 기준으로 설계한다.

## 0. 공통 규칙

### 0.1 레이아웃/스타일

디자인 상세(색상 팔레트, 버튼 위치 규칙, 근무코드 색상 체계, 모바일 디자인)는 **DESIGN.md(화면 디자인 가이드)**를 따른다.

- 상단 헤더: 앱 이름 + 로그인 사용자(이름/부서/조) + 로그아웃 버튼
- 테마: 흰색/밝은 회색 배경, 네이비/블루 포인트, 시스템 산세리프. 장식 최소화
- 필터 영역은 카드형으로 구분, 버튼 배치·순서 통일
- 근무형태는 항상 `work_types.color` 색상으로 표시 (그리드 하이라이트, 뱃지, 범례)
- "기본 Streamlit 테스트 페이지" 느낌이 나지 않도록 여백·정렬·타이포를 정돈한다

### 0.2 등록 화면 공통 패턴 (기준정보 4종 + 근무표 등록 모두 적용)

```
┌──────────────────────────────────────────────┐
│ {화면 제목}                                    │
│ {한 줄 설명}                                   │
├─ 필터 카드 ───────────────────────────────────┤
│ {검색/필터 위젯}                [조회]          │
├─ 그리드 ─────────────────────────────────────┤
│ st.data_editor (num_rows="dynamic")           │
│  - 수기 입력(key-in) 지원                       │
│  - 엑셀 범위 복사 → 붙여넣기 지원                │
│  - 행 추가(하단 빈 행) / 행 선택 삭제            │
├──────────────────────────────────────────────┤
│                       [행 추가] [행 삭제] [저장] │
└──────────────────────────────────────────────┘
```

- 버튼 순서 통일: **[조회] → [행 추가] → [행 삭제] → [저장]**
- 저장은 항상 명시적 [저장] 버튼 — 자동 저장 없음
- 저장 전 검증 → 실패 시 원인·위치를 명확히 표시하고 저장 중단
- 저장 성공/실패를 명확한 메시지로 표시 ("저장되었습니다 (반영 N건)")
- 붙여넣기 분량을 수용할 수 있도록 동적 행(`num_rows="dynamic"`) 유지

## 1. 로그인 (공통)

```
┌────────────────────────────┐
│        생산 근무표 관리         │
│                            │
│   사번  [__________]       │
│                            │
│        [ 로그인 ]           │
└────────────────────────────┘
```

- 입력 필드는 **사번 하나** (MVP: 비밀번호 없음). Enter로도 제출
- 성공: 세션 토큰 발급 → `login_sessions` 저장 + 쿠키 기록 → role별 첫 화면 이동
  - ADMIN/MANAGER → 근무표 등록/수정, USER → 내 근무표
- 실패: "등록되지 않은 사번입니다. 관리자에게 문의하세요." (퇴사자 포함)
- **로그인 유지**: 쿠키에 유효 토큰이 있으면 이 화면을 건너뛰고 자동 로그인

## 2. 기준정보 화면 (ADMIN)

모두 0.2 공통 패턴을 따른다. 그리드 컬럼 구성만 다르다.

### 2.1 사용자 등록

```
│ 사용자 등록 — 직원 정보를 등록/수정합니다. 엑셀 붙여넣기 가능      │
│ 부서 [전체▾]  조 [전체▾]  재직 [재직만▾]        [조회]           │
├────────────────────────────────────────────────────────────┤
│ 사번   이름   부서      조    직급   권한             재직      │
│ 1001  김OO  PET생산부(본동)   A조   사원   USER            ✓         │
│ 1002  이OO  PET생산부(본동)   B조   조장   MANAGER         ✓         │
│                                  [행 추가] [행 삭제] [저장]    │
```

- 부서/조/권한은 selectbox 컬럼(기준정보 목록), 재직은 checkbox 컬럼
- 검증: 사번 중복 차단, 부서·조 미등록 값 차단, 권한은 USER/MANAGER/ADMIN만
- 근무 이력이 있는 사용자는 삭제 대신 "재직 해제(is_active=false)" 안내

### 2.2 부서 등록

```
│ 부서 등록 — 부서 코드와 명칭을 관리합니다                        │
│ 사용여부 [사용중▾]                              [조회]          │
├────────────────────────────────────────────────────────────┤
│ 부서코드   부서명     순서   사용                               │
│ PET1     PET생산부(본동)     1     ✓                                 │
│                                  [행 추가] [행 삭제] [저장]    │
```

- 검증: 부서코드 중복 차단. 소속 사용자/조가 있는 부서는 삭제 대신 사용 해제 안내

### 2.3 조(팀) 등록

```
│ 조 등록 — 부서별 근무 조를 관리합니다                            │
│ 부서 [PET생산부(본동)▾]                                 [조회]          │
├────────────────────────────────────────────────────────────┤
│ 부서      조코드   조명    순서   사용                          │
│ PET생산부(본동)   A       A조     1     ✓                            │
│                                  [행 추가] [행 삭제] [저장]    │
```

- 검증: 같은 부서 내 조코드 중복 차단, 부서는 등록된 부서만 선택 가능

### 2.4 근무형태 등록

```
│ 근무형태 등록 — 근무 코드(주/야/OFF/연차 등)를 관리합니다         │
│ 사용여부 [사용중▾]                              [조회]          │
├────────────────────────────────────────────────────────────┤
│ 코드      명칭        시작    종료    색상       실근무  순서    │
│ 주       주간        07:00  15:00  #1E6FD9    ✓      1      │
│ 야       야간        23:00  07:00  #7B4FD8    ✓      2      │
│ 야-4     야간 4시간   —      —      #9A7BE3    ✓      3      │
│ 야-6     야간 6시간   —      —      #5A3DB8    ✓      4      │
│ 특주      특근(주간)  —      —      #E8862E    ✓      5      │
│ 특야      특근(야간)  —      —      #B4541B    ✓      6      │
│ OFF      휴무        —      —      #9AA0A6    ✗      7      │
│ 연차      연차휴가    —      —      #2E9E5B    ✗      8      │
│ 출산휴가  출산휴가    —      —      #D64596    ✗      9      │
│ 자녀결혼  경조(자녀결혼) —   —      #12A5A5    ✗      10     │
│                                  [행 추가] [행 삭제] [저장]    │
│ 미리보기: [주][야][야-4][야-6][특주][특야][OFF][연차]…  ← 뱃지  │
```

- 초기 코드 10종은 실제 근무표 샘플에서 확인된 것 (docs/database.md §2.4)
- 코드 정규화: trim + 영문 대문자 통일. 코드 중복 차단
- 근무표에 사용 중인 코드 삭제 시 경고 → 사용 해제 안내

## 3. 근무표 화면 (ADMIN, MANAGER)

### 3.1 근무표 등록/수정 (핵심 화면)

실제 엑셀 근무표와 동일한 **가로형 구조**(직원 정보 컬럼 + 날짜별 근무 컬럼)를 그대로 재현한다.
저장 시 세로형 `work_schedules` 레코드로 변환된다 (docs/database.md §6.1).

```
┌──────────────────────────────────────────────────────────────────────┐
│ 근무표 등록/수정 — 엑셀 근무표를 그대로 붙여넣어 저장할 수 있습니다         │
│ [2026년▾] [7월▾]  부서 [PET생산부(본동)▾]  조 [전체▾]   [조회]                  │
├──────────────────────────────────────────────────────────────────────┤
│ 사번   성명   부서     조/팀 │ 1  2  3  4  5  6  7  … 31 │             │
│ 1001  김OO  PET생산부(본동)   A조  │ 주  주  야  야  OFF OFF 주 … 야│ ← 편집 그리드│
│ 1002  이OO  PET생산부(본동)   A조  │ 야  야-4 OFF 주  주  야  야 … 주│            │
│ 1003  박OO  PET생산부(본동)   B조  │ OFF 주  특주 야  야-6 OFF 주 … 연차│         │
│                                          [행 추가] [행 삭제] [저장]     │
├─ 범례 ────────────────────────────────────────────────────────────────┤
│ [주][야][야-4][야-6][특주][특야][OFF][연차][출산휴가][자녀결혼]            │
└──────────────────────────────────────────────────────────────────────┘
```

- **표준 입력 컬럼**: **사번 · 성명 · 부서 · 조/팀 · 날짜별 근무코드(1일~말일)**
  — 날짜 열은 월 길이에 맞게 동적 생성, 주말 열은 헤더 색 구분
- 직원 정보 4컬럼은 왼쪽 고정, 날짜 컬럼은 그리드 내부 가로 스크롤 (DESIGN.md §6)
- **[조회]**: 선택한 년/월/부서(/조)의 저장된 근무표 로드. 데이터 없으면 해당 소속 재직자 목록으로 빈 그리드 생성
- 셀 입력: 근무코드 텍스트. **엑셀 범위 복사 → 그리드에 그대로 붙여넣기 가능**
- 행 추가: 하단 빈 행에 입력. 사번으로 사용자 매칭, 사번이 없으면 성명으로 매칭
- MANAGER는 본인 소속 부서만 선택 가능 (부서 필터 잠금)
- **[저장] 흐름**:
  1. 정규화(trim, 영문 대문자, 전각 처리) 후 가로형 → 세로형 변환
  2. **검증** (docs/database.md §6.2): ① 사번 존재 ② 사번 없으면 성명 매칭 ③ 성명 불일치/미등록자 오류
     ④ 부서 존재 ⑤ 조/팀 존재 ⑥ 근무코드 존재 ⑦ 같은 사번+같은 근무일자 중복 불가
     → 실패 시 행/셀 위치(성명·날짜)와 함께 오류 표시, 저장 중단
  3. 기존 데이터와 diff → **저장 전 미리보기**: "신규 12건 · 변경 3건"
     + **삭제 후보 목록** 별도 표시 (기존에 근무가 있는데 그리드에서 비워진 셀: 성명·날짜·기존 코드)
  4. **빈 셀은 자동 삭제하지 않는다** — 삭제 후보는 관리자가 [삭제 반영]을 명시적으로 선택한 경우에만 delete.
     선택하지 않으면 신규/변경만 저장
  5. 배치 생성(`schedule_import_batches`) → upsert(+ 확정된 삭제) → 달라진 셀만 `schedule_change_logs` 기록
  6. "저장되었습니다. (반영 N건)" 표시

### 3.2 전체 근무표 조회 (읽기 전용)

```
│ 전체 근무표 조회                                                 │
│ [2026년▾] [7월▾] 부서 [전체▾] 조 [전체▾] 직원 [전체▾]             │
│ 근무형태 [전체▾]                     [조회]  [엑셀 다운로드]       │
├────────────────────────────────────────────────────────────────┤
│ ┌─ 근무형태별 색상 그리드 (읽기 전용, 이름 열 고정) ──┐            │
│ └───────────────────────────────────────────────┘             │
│ ┌─ 사용자별 집계: 성명 | 주 | 야 | 야-4 | 야-6 | 특주 | 특야 | OFF | 연차 | … | 계 ─┐ │
│ └───────────────────────────────────────────────┘             │
```

- 필터: **월 / 부서 / 조 / 직원 / 근무형태** (근무형태 필터 선택 시 해당 셀만 하이라이트)
- 셀을 근무형태 색상으로 하이라이트 (pandas Styler)
- 하단에 사용자별 근무형태 집계표
- 편집 권한(ADMIN, 소속 MANAGER)이 있으면 [이 조건으로 편집] 버튼 → 3.1 화면으로 이동
- 엑셀 다운로드(선택 요구사항)

### 3.3 관리자/매니저 내비게이션 (사이드바)

- ADMIN: 근무표 등록/수정 · 전체 근무표 조회 · 사용자 등록 · 부서 등록 · 조 등록 · 근무형태 등록 · 내 근무표
- MANAGER: 근무표 등록/수정(소속 부서) · 전체 근무표 조회(소속 부서) · 내 근무표

## 4. 직원 화면 (USER, 모바일)

### 4.1 내 근무표 (기본 화면)

```
┌──────────────────┐
│ 김OO님의 근무표    │
│  [◀] 2026.07 [▶] │
├──────────────────┤
│ 오늘 7/9(목) [야] │  ← 오늘 근무 강조 카드 (색상 뱃지)
├──────────────────┤
│ 7/1 (화)  [주] 주간 07:00~15:00 │
│ 7/2 (수)  [주] 주간             │
│ 7/3 (목)  [야] 야간             │
│ 7/4 (금)  [OFF] 휴무           │
│ …                              │
├──────────────────┤
│ 이달: 주 10 · 야 6 │
│  OFF 7 · 연차 1   │
└──────────────────┘
```

- 일자별 세로 리스트 — **모바일 폭(390px)에서 가로 스크롤 없음**
- 근무형태는 `work_types.color` 색상 뱃지로 표시, 근무시간이 있으면 함께 표시
- 주말은 날짜 색 구분 (토=파랑, 일=빨강)
- ◀ ▶ 로 월 이동, 하단에 월간 근무형태 집계
- 오늘 근무가 없으면 "오늘 등록된 근무가 없습니다" 표시

### 4.2 부서 근무표 (읽기 전용, 선택)

- 본인 부서(·조)의 월간 그리드를 축소 표시 (가로 스크롤 허용, 이름 열 고정)
- 또는 "날짜 선택 → 그날 부서원 전체의 근무" 리스트 형태 병행

### 4.3 직원 내비게이션

- 상단 탭: [내 근무표] [부서 근무표] + 로그아웃
- USER는 관리자/매니저 메뉴에 접근 불가 (URL 직접 접근 포함, 앱 레벨 차단)
